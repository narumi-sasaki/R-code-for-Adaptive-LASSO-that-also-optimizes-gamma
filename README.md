# R-code-for-Adaptive-LASSO-that-also-optimizes-gamma
This code was created for variable selection on large-scale experimental data collected according to a D-optimal design assuming a quadratic model. In the first stage, Elastic Net with leave-one-out cross-validation (LOOCV) is used; in the second stage, LASSO based on the BIC criterion is used, with hyperparameters determined via Bayesian optimization. The selected variables need to be separately modeled while taking hierarchy (heredity) into account.
