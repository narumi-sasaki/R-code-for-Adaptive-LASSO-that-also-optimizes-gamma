# R-code-for-Adaptive-LASSO-that-also-optimizes-gamma
In the first stage, Elastic Net with LOOCV is used, and in the second stage, LASSO based on the BIC criterion is used, with hyperparameters determined via Bayesian optimization.
This code was created for variable selection on large-scale experimental data collected based on a design generated by D-optimal design assuming a quadratic model. The selected variables need to be separately modeled while taking hierarchy (heredity) into account.
